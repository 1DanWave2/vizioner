## Согласовано с Данеком

- Настроение: **музейная тишина** (Tate, MoMA, Gagosian как референсы)
- Стек: **чистый HTML/CSS/JS**
- Главное на главной: **превью каталога** (не манифест)

- Логотип: **текстовый**, только слово «Визионер» крупным serif'ом
- Админка: **полноценная admin.html** с drag&drop, inline edit, экспортом JSON

## Этап 1. Дизайн-система (CSS + типографика)

### 1.1 Палитра

| Token | Значение | Где |
|---|---|---|
| `--bg` | `#FAF8F4` | Фон (айвори) |
| `--ink` | `#1A1A1A` | Основной текст |
| `--ink-soft` | `#5A5550` | Подписи, мета |
| `--line` | `#E5E1D8` | Тонкие разделители |
| `--paper` | `#FFFFFF` | Карточки, модалки |
| `--ink-deep` | `#0A0A0A` | Hover/активные ссылки |

Никаких градиентов. Никаких коричневых акцентов. Никаких теней (или максимум одна тончайшая).

### 1.2 Типографика

- Заголовки: **Cormorant Garamond** (Google Fonts, weights 400/500)
- UI/мета: **Inter** (Google Fonts, weights 400/500)
- Размеры по шкале: 14 / 16 / 18 / 24 / 32 / 48 / 72 (для hero)
- Line-height: 1.2 для заголовков, 1.6 для текста
- Letter-spacing: 0.02em для UPPERCASE-меток

### 1.3 Принципы

- Углы 0px (или 2px max) — без скруглений
- Без shadows на карточках. Hover = только лёгкое движение текста или подчёркивание
- Сетка с большими отступами (60-80px между секциями)
- Подписи в стиле музейных этикеток: UPPERCASE 11px tracking + ровный текст

## Этап 3. Управление работами

### 3.1 Структура данных (`data/works.json`)

Расширяю схему — добавляю поле `featured` (для главной) и `slug` (для красивого id):

```json
{
  "id": "esenov-rosi",
  "slug": "rosi",
  "title": "Розы",
  "artist": "Есенов",
  "year": 2023,
  "type": "живопись",
  "genre": "натюрморт",
  "material": "Холст, масло",
  "technique": "Масло",
  "size": "60×70 см",
  "size_w": 60,
  "size_h": 70,
  "price": null,
  "price_label": "По запросу",
  "description": "...",
  "image": "assets/img/works/esenov-rosi.jpg",
  "featured": false,
  "sort": 0
}
```

`sort` — для ручной сортировки в админке.

### 3.2 admin.html

Локальная страница, не публикуется (добавлю в `.gitignore` или добавлю простую парольную защиту через JS).

**Функции:**

1. **Список всех работ** — таблица с колонками: миниатюра, название, автор, тип, год, действия
2. **Кнопка «+ Добавить работу»** → форма со всеми полями
3. **Drag&drop фото** — через File System Access API (Chrome/Edge) или fallback "сохрани файл туда-то"
4. **Inline edit** — клик по ячейке, поле становится редактируемым
5. **Удаление** — с подтверждением
6. **Reorder** — drag-handle на каждой строке для перетягивания
7. **Featured toggle** — звёздочка для отметки работ для главной
8. **Кнопка «Скачать обновлённый works.json»** → браузер сохраняет файл, ты кладёшь его в `data/`, коммитишь
9. **Импорт** — drag&drop существующего works.json для редактирования

**Технология:** vanilla JS + одна страница. Все данные в памяти, сохраняем через скачивание JSON.

### 3.3 Скрипт миграции

Существующие 24 работы в `works.json` имеют:
- двойные `.jpg.jpg` в полях `image`
- разнобой полей (`author` и `artist` параллельно — оставлю один `artist`)

Сделаю Python-скрипт `tools/migrate.py` который:
- Переименует файлы фото (`uglach-Granat.jpg.jpg` → `uglach-granat.jpg`)
- Обновит JSON под новую схему
- Сохранит бэкап старого works.json
