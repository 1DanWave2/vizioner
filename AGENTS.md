## Краткая сводка для быстрой ориентации

- **Проект:** Визионер — онлайн-галерея современного российского искусства + услуга подбора под интерьер
- **Стек:** чистый HTML/CSS/JS, без фреймворков, без npm, без сборки
- **Источник данных:** `data/works.json` (24 работы), `data/artists.json` (4 художника)
- **Локальный запуск:** `python3 -m http.server 8000`
- **Дизайн-эстетика:** музейная тишина (айвори/чёрный, serif Cormorant Garamond + Inter, без скруглений и теней) — **не менять**
- **Владелец:** Данек, общение на русском неформальное

## Что НЕ делать

- Не добавлять npm/фреймворки/сборщики
- Не вводить цветные акценты, скругления, тени
- Не делать рефакторинг ради рефакторинга — точечные правки только
- Не менять решения по дизайну/позиционированию без явного запроса
- Не использовать пафосные тексты («искусство меняет жизнь» и т.п.) — только конкретика

## Что обязательно делать

- Прежде чем менять файл — прочитай его
- Прежде чем менять контентную страницу — посмотри `TEMPLATES.md`
- При изменении CSS — придерживайся design-tokens из `:root` в `assets/css/styles.css`
- При работе со схемой данных — синхронизируй `data/works.json` и `assets/js/admin.js`
- Перед коммитом — прогоняй проверки из раздела «Как локально запустить» в `CONTEXT.md`
