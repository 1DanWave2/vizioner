## 1. О проекте

**Визионер** — онлайн-галерея современного российского искусства и сервис подбора художественных работ под интерьер.

**Что мы делаем:**
- Курируем работы современных российских художников (живопись, графика, постеры, скульптура малых форм)
- Ведём онлайн-каталог
- Помогаем частным клиентам подобрать работы под конкретный интерьер (бесплатная услуга «Подбор» — главная фича внутри галереи)
- Сопровождаем клиента на этапе выбора и доставки

**Кто мы:**
- Мини-компания (фактически — владелец + Claude как ассистент)
- Работаем **напрямую с художниками** (не перепродаём через третьих лиц) — это даёт гибкость в цене и эксклюзив
- Москва, но доставляем по всей России

## 3. Бизнес-стратегия

**Бюджет на маркетинг:** 5 000 ₽/мес (микро-бюджет — полноценный TG Ads нереален, минимум там ~100к через посредников)

**Цели на 6 месяцев (согласовано):**
- Приоритет: бренд + узнаваемость
- Обязательный минимум: **2–3 валидирующих продажи в месяц** к 6-му месяцу — нужно для обратной связи от рынка, иначе бренд строится в вакууме

**Стратегия привлечения (80% органика + 20% точечные платные выстрелы):**
1. **Pinterest** — главная ставка для долгосрока (бесплатно, медленно растёт, готов скрипт массовой загрузки в `tools/pinterest_export.py`)
2. **Холодная рассылка дизайнерам интерьеров** — 10–15 контактов в неделю, шаблон в `TEMPLATES.md`
3. **Контент в TG-канале** — 3 поста в неделю по шаблонам из `TEMPLATES.md`
4. **Гостевые посты в чужих TG-каналах** — бесплатно, в обмен на полезный контент

**Что мы НЕ делаем:**
- Не запускаем платную рекламу до того, как сайт+контент готов (зальём бюджет в воронку с дырой)
- Не пытаемся продавать всем (фокус — частник в дом)
- Не используем пафосные тексты «искусство меняет жизнь» — только конкретику, кейсы, цифры
- Не выходим на международный рынок сейчас
- Не делаем 3D-туры и сложную интерактивность — трата ресурсов

## 4. Дизайн-направление

**Утверждено на старте редизайна:**

| Параметр | Значение |
|---|---|
| Настроение | **Музейная тишина** — Tate, MoMA, Gagosian как референсы |
| Палитра | Айвори `#FAF8F4` фон, почти-чёрный `#1A1A1A` текст, тонкие линии `#E5E1D8` |
| Типографика | **Cormorant Garamond** (serif, заголовки) + **Inter** (sans, мета) |
| Скругления | **0px** везде |
| Тени | **0** теней |
| Акценты | Без коричневых градиентов, без цветных акцентов — только чёрный/айвори |
| Анимация | Плавная, через единые easing-токены `--ease`, `--ease-out`, `--ease-in-out` |
| Логотип | Текстовый + SVG-знак (пирамида с глазом) в шапке и hero на главной |

**Принципы:**
- Главное на главной странице — **превью каталога**, не пафосный hero-манифест
- Карточки работ — без рамок, без теней, без скруглений (фото говорит само)
- Толкача на услугу «Подбор» — тёмный CTA-баннер на главной
- Логотип при наведении плавно переворачивается на 180°
- Все интерактивные элементы имеют чистый hover-feedback (без «дёрганий»)

**Схема данных `works.json` (одна запись):**

```json
{
  "id": "uglach-posle-dojdya",
  "title": "После дождя",
  "artist": "Углач",
  "year": 2022,
  "type": "живопись",
  "genre": "пейзаж",
  "material": "Холст масло",
  "technique": "Масляные краски",
  "size": "60×70 см",
  "size_w": 60,
  "size_h": 70,
  "price": null,
  "price_label": "По запросу",
  "description": "Пейзаж. После дождя.",
  "image": "assets/img/works/uglach-posle-dojdya.jpg",

  "sort": 0

```

- `id` = slug (lowercase, дефисы), без расширения

- `featured: true` = работа показывается на главной странице
- `sort` = порядок сортировки в админке (drag&drop)
- `price: null` означает «по запросу»

**Схема `artists.json`:** `slug`, `name`, `tagline`, `bio_short`, `bio_full`, `techniques`, `themes`.

## 7. Конвенции разработки

**Стиль кода:**
- HTML — семантический, без лишних `div`-обёрток
- CSS — design-tokens в `:root`, использовать spacing-шкалу `--s-1` до `--s-10` (8-base)
- JS — vanilla ES modules, без зависимостей
- Имена файлов лога: `slug-lowercase-dashes.jpg`

**Что НЕ делать в коде:**
- ❌ Не добавлять npm/фреймворки/сборщики
- ❌ Не добавлять inline-стили в новые элементы (использовать утилитные классы или CSS)
- ❌ Не использовать `!important` (не должно быть нужно при правильной структуре)
- ❌ Не использовать тени и скругления — это против дизайн-направления
- ❌ Не использовать цветные акценты (зелёный/синий/коричневый)
- ❌ Не дублировать header/footer в каждом HTML — они рендерятся через `app.js` в `<div id="site-header">` / `<div id="site-footer">`

**Что обязательно делать:**
- ✅ Все формы и контент должны быть отзывчивыми (mobile-first)
- ✅ `prefers-reduced-motion` — обязательно учитывать (уже в CSS)
- ✅ Подключать `favicon.svg` и шрифты в каждом HTML
- ✅ Использовать единые easing-токены для всех анимаций

**Безопасность:**
- Пароль админки — в SHA-256 хеше в `admin.js`. По умолчанию `vizioner-admin` (слабый, поменять перед деплоем)
- В админке `safeImagePath()` валидирует URL картинок (не пропускает `javascript:`/`data:` схемы)
- Контакты в HTML имеют fallback значения (для случая когда JS не загрузился)

## 8. Как локально запустить и проверить

```bash
cd ~/Documents/Vizioner
python3 -m http.server 8000
```

Открыть `http://127.0.0.1:8000/`.

> Через `file://` сайт работать не будет (fetch к `data/works.json` блокируется браузером CORS). Только через http.

**Проверки перед коммитом:**

```bash
# JSON валиден
python3 -c "import json; json.load(open('data/works.json'))"
python3 -c "import json; json.load(open('data/artists.json'))"

# Python tools синтаксис
python3 -m py_compile tools/migrate.py tools/pinterest_export.py

# JS синтаксис (если есть node)
node -e "
const fs = require('fs');
['assets/js/app.js','assets/js/home.js','assets/js/gallery.js','assets/js/admin.js','assets/js/artists.js','assets/js/site.config.js'].forEach(f => {
  const src = fs.readFileSync(f, 'utf8');
  try {
    new Function(src.replace(/^import.*from.*\$/gm, '').replace(/^export /gm, ''));
    console.log('OK ' + f);
  } catch (e) { console.log('FAIL ' + f + ': ' + e.message); }
});
"

# HTTP — все страницы отдают 200
for path in / gallery.html artists.html service.html about.html contact.html admin.html; do
  curl -s -o /dev/null -w "%{http_code} $path\n" http://127.0.0.1:8000/$path
done
```

## 11. Историческое: что было сделано

Краткая хронология решений (для понимания, почему всё так):

1. **Стартовый сайт** был с коричневыми градиентами, скруглениями, тенями — «уютная кофейня» эстетика
2. **Полный редизайн** — всё переписано под музейную эстетику (Tate/MoMA/Gagosian)
3. **Миграция данных** — `tools/migrate.py` исправил двойные `.jpg.jpg` в именах файлов, унифицировал поля JSON
4. **Логотип** — нарисован SVG (пирамида с глазом) на основе скриншота владельца
5. **Услуга «Подбор»** — выделена в отдельную страницу `service.html` + большой CTA на главной
6. **Художники** — отдельная страница `artists.html` с био и работами
7. **Анимация** — единые easing-токены, плавные hover'ы, reveal-on-scroll, переворот лого на 180°
8. **Админка** — добавлена `admin.html` с drag&drop, inline-edit, экспортом JSON, парольная защита
9. **Стратегия v2 (5к₽/мес)** — план под микро-бюджет, 80% органика
10. **Документация** — `CONTEXT.md`, `TEMPLATES.md`, `TODO.md`, `AGENTS.md` для непрерывности при смене ассистентов
