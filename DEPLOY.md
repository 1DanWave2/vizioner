# Развёртывание Визионер на Timeweb

Пошаговая инструкция: от чистого хостинга до работающего сайта на `artvizioner.ru`.
Срок: 30-60 минут включая подтверждение DNS.

---

## Что нужно сделать (общий план)

1. Привязать домен `artvizioner.ru` к хостингу Timeweb
2. Загрузить файлы сайта в папку хостинга
3. Включить HTTPS (бесплатный сертификат Let's Encrypt)
4. Зарегистрировать в Яндекс.Вебмастер и Google Search Console
5. Подключить Яндекс.Метрику (опционально, но важно)

---

## Шаг 1 · Привязать домен к хостингу

### В панели Timeweb (timeweb.com/ru):

1. Войти → раздел **«Сайты»**
2. **«Добавить сайт»** → название `artvizioner`
3. Появится **корневая папка** сайта — обычно `/var/www/USERNAME/data/www/artvizioner.ru/`
4. Заметить путь, он понадобится в Шаге 2

### Привязка домена (если домен в Timeweb):

5. **«Домены»** → найти `artvizioner.ru`
6. **«Привязать к сайту»** → выбрать сайт `artvizioner`

### Если домен у другого регистратора:

В DNS-настройках регистратора прописать **A-запись** на IP-адрес сервера Timeweb (см. в Панели → «Сайты» → «Информация о сайте»).

DNS-распространение занимает от 15 минут до 24 часов.

---

## Шаг 2 · Загрузить файлы сайта

### Через файловый менеджер Timeweb (проще):

1. **«Файловый менеджер»** → перейти в корневую папку сайта (`/.../data/www/artvizioner.ru/`)
2. Удалить все стандартные файлы которые там лежат (`index.html` от Timeweb, и т. д.)
3. Скачать архив сайта с GitHub:
   - https://github.com/1DanWave2/vizioner → зелёная кнопка **`<> Code`** → **Download ZIP**
4. Распаковать ZIP на компьютере
5. Через файловый менеджер Timeweb — кнопка **«Загрузить»** → выделить все файлы и папки из распакованной папки `vizioner-main/` и загрузить

### Через FTP (быстрее если есть FTP-клиент):

1. В Timeweb: **«FTP»** → создать FTP-аккаунт для папки сайта
2. Подключиться через FileZilla/Cyberduck с этими данными
3. Перетянуть все файлы из локальной папки в корень сайта

### Важно

После загрузки в корне должны быть видны:
```
artvizioner.ru/
├── index.html
├── gallery.html
├── artists.html
├── service.html
├── about.html
├── contact.html
├── admin.html
├── 404.html
├── .htaccess
├── robots.txt
├── sitemap.xml
├── data/
├── assets/
└── ...
```

**Папки которые НЕ нужны на хостинге** (можно не загружать чтоб сэкономить место):
- `.git/`
- `.backup/`
- `tools/`
- `tmp/`
- `print/`
- `cases/`
- Все `*.md` файлы (README.md, CONTEXT.md, AGENTS.md, TODO.md, TEMPLATES.md, DEPLOY.md)

Эти папки и так блокируются от внешнего доступа через `.htaccess`, но если хочешь чистоту — не заливай.

## Шаг 3 · Включить HTTPS

1. В панели Timeweb: **«Сайты»** → выбрать `artvizioner`
2. Вкладка **«SSL сертификаты»** → **«Заказать бесплатный Let's Encrypt»**
3. Подтвердить → подождать 5-10 минут
4. Когда выдадут — включить **«Перенаправлять HTTP → HTTPS»** (если ещё не включено в `.htaccess`)

Проверить: открыть **https://artvizioner.ru** — должен загрузиться сайт с замочком в адресной строке.

## Шаг 4 · Регистрация в поисковых системах

### Яндекс.Вебмастер (для Яндекса — основной поисковик в РФ)

1. https://webmaster.yandex.ru/ → войти
2. **«Добавить сайт»** → ввести `https://artvizioner.ru`
3. Подтвердить владение **HTML-файлом**:
   - Скачать предложенный файл `yandex_XXXX.html`
   - Загрузить в корень сайта через файловый менеджер Timeweb
   - Нажать «Проверить» в Яндекс.Вебмастере
4. После подтверждения:
   - **«Файлы Sitemap»** → добавить `https://artvizioner.ru/sitemap.xml`
   - **«Региональность»** → указать Москва (или Россия)
   - **«Турбо-страницы»** → включить (бесплатно ускоряет загрузку для мобильных)

### Google Search Console

1. https://search.google.com/search-console → войти
2. **«Добавить ресурс»** → выбрать **«Префикс URL»** → ввести `https://artvizioner.ru`
3. Подтвердить через HTML-файл (по аналогии с Яндексом)
4. После подтверждения:
   - **«Sitemap»** → добавить `sitemap.xml`

## Шаг 5 · Яндекс.Метрика (аналитика — что делают посетители)

1. https://metrika.yandex.ru/ → **«Добавить счётчик»**
2. Адрес: `artvizioner.ru`
3. **Включить «Вебвизор»** — записывает сессии посетителей, можно посмотреть как они кликают
4. Получить **код счётчика** (вид: `ym(YOUR_ID, "init", ...)`)
5. Вставить в `assets/js/app.js` функцию `initLayout` в самый конец:

```javascript

(function(m,e,t,r,i,k,a){m[i]=m[i]||function(){(m[i].a=m[i].a||[]).push(arguments)};
m[i].l=1*new Date();k=e.createElement(t),a=e.getElementsByTagName(t)[0],k.async=1,k.src=r,a.parentNode.insertBefore(k,a)})

ym(YOUR_COUNTER_ID, "init", {clickmap:true, trackLinks:true, accurateTrackBounce:true, webvisor:true});
```

Заменить `YOUR_COUNTER_ID` на свой номер. После загрузки сайта — открой в браузере, открой DevTools → Network → проверь что запрос на `mc.yandex.ru` идёт.

## Шаг 7 · Обновления сайта после деплоя

Каждый раз когда что-то меняешь:
1. Через GitHub Pages (как сейчас) — `git push` и через минуту обновляется
2. Через Timeweb — нужно вручную загрузить изменённые файлы через файловый менеджер или FTP

Чтоб упростить, можно настроить **автоматический деплой** через GitHub Actions при пуше в main — попроси Claude/Codex сделать `.github/workflows/deploy.yml` с FTP-загрузкой. Это даст: пушим в git → файлы автоматически летят на Timeweb. Сэкономит время.

## Если что-то не работает

### Сайт открывается но без стилей и картинок
Проверь что папка `assets/` загружена со всем содержимым и пути в HTML правильные. Через файловый менеджер открой `assets/css/styles.css` — должен открыться текст CSS.

### 403 Forbidden на главной
В корне нет `index.html`. Проверь.

### Не работает редирект www → без www
`.htaccess` не загрузился (он скрытый файл!). В файловом менеджере включи показ скрытых файлов и проверь что `.htaccess` есть.

### Не приходит SSL-сертификат
Подожди 24 часа после привязки домена. DNS должен распространиться.

### Админка не пускает
Пароль `Danila160@`. Если забыл — пересчитай SHA-256:
```bash
echo -n "новый_пароль" | shasum -a 256
```
и подставь в `assets/js/admin.js` в константу `PASSWORD_HASH`.
