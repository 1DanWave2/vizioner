# Визионер

Онлайн-галерея современного искусства и подбор арт-решений для интерьеров.
Чистый статический сайт: HTML + CSS + JS, без фреймворков и бэкенда.

> 📘 **Для AI-агентов и новых разработчиков:** начни с [CONTEXT.md](CONTEXT.md) —
> там полный бриф проекта (бизнес-контекст, стратегия, дизайн-направление,
> архитектура, конвенции). Активные задачи — в [TODO.md](TODO.md).
> Готовые тексты для контента — в [TEMPLATES.md](TEMPLATES.md).

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открыть `http://127.0.0.1:8000/`.

> **Важно:** через `file://` сайт работать не будет (fetch к `data/works.json` блокируется браузером). Только через http.

## Как добавлять / редактировать / удалять работы

### Способ 1: Админка (рекомендуется)

1. Открой `http://127.0.0.1:8000/admin.html`
2. Введи пароль: **`vizioner-admin`** (изменить — см. ниже)
3. Дальше:
   - **+ Новая работа** → форма + drag&drop фото
   - Клик по любой ячейке таблицы — inline edit
   - **★** — отметить работу как featured (показывать на главной)
   - **Удалить** — убрать работу из JSON (фото с диска не удалится — снеси руками если надо)
   - Перетягивание строк за `⋮⋮` — смена порядка
4. По окончании — **«Сохранить works.json»**:
   - Если ты подключил папку проекта (кнопка **«Подключить папку проекта»**, работает в Chrome/Edge) — JSON и фото запишутся прямо в файлы.
   - Иначе — файлы скачаются в `~/Downloads/`, переложи их вручную в `data/works.json` и `assets/img/works/`.
5. Закоммить и запушь:
   ```bash
   git add data/works.json assets/img/works/
   git commit -m "Добавлена работа: <название>"
   git push
   ```

#### Изменить пароль админки

```bash
echo -n "новый_пароль" | shasum -a 256
```

Скопируй хеш и подставь в `assets/js/admin.js`:

```js
const PASSWORD_HASH = "сюда_хеш";
```

### Способ 2: Руками в JSON

Открой `data/works.json`, добавь блок:

```json
{

  "title": "Рассвет",
  "artist": "Иванов",
  "year": 2025,
  "type": "живопись",
  "genre": "пейзаж",
  "material": "Холст",
  "technique": "Масло",
  "size": "60×80 см",
  "size_w": 60,
  "size_h": 80,
  "price": null,
  "price_label": "По запросу",
  "description": "Раннее утро в горах.",
  "image": "assets/img/works/ivanov-rassvet.jpg",
  "featured": false,
  "sort": 999

```

Положи фото в `assets/img/works/ivanov-rassvet.jpg`. Имя файла должно совпадать с `id`.

## Как работает дизайн

- Палитра: айвори фон (`#FAF8F4`), почти-чёрный текст (`#1A1A1A`), тонкие линии (`#E5E1D8`).
- Типографика: **Cormorant Garamond** (serif, заголовки) + **Inter** (sans, мета). Загружаются с Google Fonts.
- Принцип: ноль скруглений, ноль теней, много воздуха. Карточки работ — без рамок, фото говорит само.

Менять цвета и шрифты — в `:root` блоке `assets/css/styles.css`.

## Как менять контакты

Один файл: [`assets/js/site.config.js`](assets/js/site.config.js). Меняй там — отразится на всех страницах и в футере.

## Деплой

Любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages.

### GitHub Pages

В Settings → Pages → Source: deploy from branch `main` (root).

Если у тебя проект-репо `username.github.io/vizioner` — пути уже работают (всё относительное). Если кастомный домен — тоже работает.
